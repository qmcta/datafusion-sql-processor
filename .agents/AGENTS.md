# **🤖 Project Agents & Skills (v2)**

This repository integrates AI-driven agents, specialized skills, and autonomous loop engineering workflows for DataFusion SQL Processor.

---

## **👥 Development Team Roles (Loop Engineering)**

### **1. Architect & Developer**
- **Role Name**: `Developer Agent`
- **Primary Duties**:
  - Read `spec.md` and project source code to understand architectural and functional requirements.
  - Read failure diagnostics from `test_results.log` (if generated by the QA Agent).
  - Implement and refactor Rust application code (`src/`), dependencies (`Cargo.toml`), and SQL files (`data/`).
  - Ensure changes adhere to strict type-safety, ownership/borrowing semantics, and performance considerations.
- **Associated Skill**: `.agents/skills/implement.md` (`implement`)

### **2. QA & Verification Engineer**
- **Role Name**: `QA Agent`
- **Primary Duties**:
  - Execute automated test suites and compiler checks (`cargo test`, `cargo check`, `cargo clippy`).
  - Analyze compiler errors, borrow check errors, and test failure tracebacks.
  - Persist failing logs into `test_results.log` and formulate actionable feedback for the `Developer Agent`.
  - Evaluate verification exit criteria: confirm all tests pass, or increment retry cycle if failures remain.
- **Associated Skill**: `.agents/skills/audit_and_test.md` (`audit_and_test`)

### **3. Human Supervisor / Reviewer**
- **Role Name**: `User / Human Reviewer`
- **Primary Duties**:
  - Review proposed implementation plans and high-level architectural decisions.
  - Intervene when autonomous retry loops reach their maximum threshold (e.g. 5 iterations).

## **🛠️ Available Skills & Workflows**

### **1. Autonomous Engineering Loop (`dev_loop` / `startcycle`)**
- **Goal**: Full autonomous pipeline: `spec.md` -> Code Implementation -> Test Execution -> Error Reflection & Retry -> Verified Completion.
- **Trigger**: `/dev_loop` or `/startcycle`
- **Workflow Path**: `.agents/workflows/dev_loop.md` and `.agents/skills/dev_loop/SKILL.md`

### **2. Implement Requirements (`implement`)**
- **Goal**: Implement Rust source code matching `spec.md`, incorporating bugfix context from `test_results.log`.
- **Path**: `.agents/skills/implement.md` and `.agents/skills/implement/SKILL.md`

### **3. Audit and Test Code (`audit_and_test`)**
- **Goal**: Run automated tests/linters, analyze error logs, and manage the retry loop decision.
- **Path**: `.agents/skills/audit_and_test.md` and `.agents/skills/audit_and_test/SKILL.md`

### **4. Generate Slides (`generate_slides`)**
- **Goal**: Transform technical documents (Markdown, Source Code, or Text files) into a professional, Google Cloud-styled Marp presentation using `.agents/DESIGN.md`.
- **Path**: `.agents/skills/generate_slides/SKILL.md`

## **🔄 Verification Loops (検証ループ) Protocol**

When running an autonomous engineering cycle:
1. **Context Initialization**: The agent reads `spec.md` to baseline requirements.
2. **Implementation Phase (`implement`)**: `Developer Agent` writes or refactors code.
3. **Audit & Testing Phase (`audit_and_test`)**: `QA Agent` runs `cargo test` / `cargo check` / `cargo clippy`.
4. **Autonomous Decision**:
   - **PASS**: Delete `test_results.log`, output completion summary, and terminate loop.
   - **FAIL**: Write error logs to `test_results.log`. Pass log to `Developer Agent` and retry up to 5 times.
   - **MAX RETRY REACHED**: Stop loop, output summary of unresolved issues, and escalate to the user.
